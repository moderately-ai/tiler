Update to the dependency edge I added earlier today. `prototype-public-compiler-api` has landed its request half: an out-of-crate caller can now install a `FrozenLoweringCapabilityRegistry` and compile through it. That is **not** sufficient for this ticket.

What landed is target-profile *selection*. `PrototypeTargetProfile` still has one constructor, `governed()`, and `verify_request` rejects any other profile twice over — at the boundary and again in `for_target`. This ticket needs a caller-authored profile carrying its own honourability rows to reach `feasibility`, which is *declaration*, and declaration is a validation job rather than a visibility change.

So the edge is directionally right and the remaining prerequisite is narrower and nameable: admitting a caller-declared target profile, with whatever validates one. Worth filing separately if this ticket is picked up before that exists, rather than discovering it mid-implementation.
